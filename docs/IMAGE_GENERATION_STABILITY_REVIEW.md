# 图片生成稳定性代码 Review

评审日期：2026-11-04。范围覆盖图片操作准备、模式选择、提交受理、原会话定位、产物归属、候选下载、显式恢复与重发、重启恢复以及观察器清理。本文记录当前工作树中的修复与验证，不代表版本已发布。豆包真实图片任务已完成本报告下述单次端到端验证；不据此宣称所有平台状态均已覆盖。

## 本次现场与原因

用户再次遇到的错误来自原图片任务，任务 ID 前缀为 `62ced5f0`，并非本次又创建了一个生成任务。只读任务与日志回读表明：该任务在 2026-11-03 已保存提交意图，但原受理核对未取得具体会话地址，也未形成可跨重启使用的媒体消息收据。2026-11-04 重启后，原账号 WebView 加载的是根页；再次点击继续时，页面没有用户消息和助手消息，原恢复逻辑仍等待到核对超时。

这里有两类不同问题：发送后的页面异步变化，需要在原运行内持续读取真实证据；重启后原会话已经不在当前页，则需要先恢复定位。延长等待不能使空根页自动变成原历史会话。以前的多次点击还会重新开启只读核对，恰好在页面稳定后成功，因此掩盖了定位与观察生命周期的问题。

原任务的提交意图、账号、运行和输入仍须保留。未读到受理证据不能被解释为“肯定没有发送”，也不能成为自动重发的授权。

## 复发复核：图片模式入口误判

此前离线回归不足以支持“已经处理好”的判断。用户随后报告“图片模式入口未就绪，已在提交前停止”；本轮直接检查当前页面与原任务，确认新关联任务 `d26a2b91` 尚未提交，两次均停在模式准备阶段。

真实页面将编辑器所在的 `#input-engine-container`、技能栏和已选技能分散在共同 `.guidance-input-surface` 的兄弟分支。模式定位优先选较窄的 engine，漏读真正的图像入口和选中标记；直接技能入口冷激活时还会异步重建控件，旧流程把短暂缺失误判为需要再次点击模式菜单。多点继续可能恰好遇到已稳定页面，因而暂时成功。

本轮两处探针统一定位唯一可见的共同输入区，保留侧栏排除与多输入区拒绝。直接技能按钮仅点击一次，随后沿现有 15 秒预算连续回读目标技能；只有实际点击模式触发器才进入菜单流程。没有增加提交次数或放宽发送证据。任务日志新增脱敏的模式结果、路径和耗时，便于区分入口缺失与选中确认失败。

新增真实兄弟分支 DOM 回归执行实际序列化脚本，覆盖 engine 外深层技能标记、3 秒异步重建、禁止重点击新模式触发器、多输入区歧义、隐藏旧输入区和诊断回调异常。真实页面冷切换约 2 秒成功；随后只点击一次“继续本次任务”，原关联任务正常生成，模式回读约 519 ms，任务、制作步骤和图片操作完成，3 张图片候选落盘，未自动采用。

另在真实产物验收中发现原下载读取了 384×216 缩略图。平台同一助手图片卡的固定 provider 字段明确给出 2848×1600 原图；现仅从同条消息、同卡精确关联的 `image_ori`／`image_ori_raw` 取原图，缩略图尺寸声明不能证明原图。缺原图或部分候选尚未关联时保持只读等待。旧版消息缓存按证据版本失效，不把曾接纳的缩略图升级为原图。

已沿原任务严格读取 3 个原图地址，经 TaskService 登记原运行产物，再用正式制作服务补下载并导入候选。3 个文件均解码为 2848×1600；原 run、提交时间、原文件与正式选图保留，未再发送生成请求，未自动采用。预览默认选最新候选，原缩略图历史仍保留。

现场还确认媒体收据可能因受理初期 provider 未完整挂载而漏存：旧时序先保存具体会话地址，随后完成图片时不再补读。现于原图稳定后、任务完成前，在原账号／运行／控制器守卫内再调用同一收据保存逻辑；证据仍不完整时不伪造收据，也不恢复发送权限。

## 恢复入口与状态约定

原账号、task、run 和本次输入构成恢复边界。已有受理收据或产物只能恢复读取和下载，不能恢复同一运行的发送权限。收据不能由根页地址、编辑器草稿、相似提示词、页面“生成中”文字、其他账号或其他运行推断出来。

打开原账号只揭示该账号已有 WebView，不清理草稿、不创建新对话、不点击发送。对缺定位旧任务，用户先在账号历史中打开本次图片对话，再继续核对。页面预检证明“存在可读会话”，后续严格核对才决定能否绑定为原任务；预检本身不保存会话归属。

图片先生成并下载为候选，再由用户预览并明确采用。下载成功、文件可解码和后台任务完成均不等于用户采用；换图及重发不会偷偷覆盖原正式图。部分候选下载失败时保留已保存候选，恢复只补原缺项。

## 仍需保留的限制

- 已经丢失具体会话地址且从未保存有效收据的历史任务，无法只凭任务 ID 或提示词自动重建原会话。找回原会话后读取原结果，或由用户明确确认重发一次，仍是必要的恢复分支。
- provider、技能控件或真实图片卡结构变化后，证据不足时继续暂停并显示真实原因。不能通过放宽到整页文字、任意图片、跨账号会话或自动补发提高表面成功率。
- 原媒体已过期、平台实际拒绝、登录失效、人机验证、素材授权或文件权限错误仍可能阻断任务。修复保证正确归属、保留记录和可解释恢复，不承诺所有原结果都能取回。
- 本轮只接续用户这条明确未提交的关联任务，原不明提交任务仍保留；后续补收原图只读取已有结果。没有完成 Dola 端到端验收，本报告不改变 Dola 尚未生产可用的结论。
