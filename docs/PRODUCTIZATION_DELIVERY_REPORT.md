| 完整画布 | 阶段 4／5 都保留故事素材栏、每镜一行四列、网格白色节点、原几何、平移缩放、镜头定位和全文编辑；去掉裁列呈现。 |
| 所有图片 | 人物／道具／场景／首帧／尾帧无论生成或上传都先保存候选、预览用途，再明确“采用这张”。原图在新图采用前保持；替换后保留历史并标记受影响成果复核。 |
| 图片上传与引用 | 原生文件选择器按所在对象归属，不要求内部 ID。文件解码、摘要与用途核对后才可采用。未采用／待复核图片被正式引用服务拒绝。旧明确基础素材确认兼容，旧关键帧文件不默认升级为已采用。 |
| 多张图片与恢复 | 同次生成有效图片全部作为候选保存；部分下载失败保留已下载候选，恢复只补原下载。批次完成、下载、文件验证与人工选择分别处理。 |
| 自动正文 | 新分析、资产、提示词与修订均先保存候选，显式采用才更新当前内容。自动创作正文来自真实 Chat 回复；程序只解析、保存、校验与映射。 |
| 自由豆包交流 | 从当前方案／素材／镜头进入具体关联会话，保留真实网页交流入口。自动读取可辨认的具体助手回复，用户明确选择、查看目标与完整拟应用内容，再确认采用。没有默认最后一条回复。 |
| 回复保护 | 绑定实际任务、账号、原运行和具体会话；回复用完整正文、前一用户消息及平台标识核对。采用前再次只读检查；旧版本、错会话、变化中或迟到回复不能覆盖新内容。未保存工作室草稿和豆包输入框未发送草稿会阻断采用。 |
| 对话与任务并发 | 自由交流期间保护账号，其他任务入口不自动切会话。保护身份写入现有源 Chat 任务台账，重启后也阻止同账号排队提交；采用／结束后精确释放并刷新任务缓存。未收取制作任务先处理，不能用自由回复破坏其输入快照。 |
| 成果与恢复 | 每镜真实素材、提示词、文件验证、对应关系、缺项及质量结论分开显示。视频生成、提示词修订和重新下载为独立操作。不显示未实现的完整成片。 |

发送方式仍是现有**自动发送**：正式提交记录保存后，现有执行入口单次发送并回读。没有把改文案当成人工发送实现，没有增加“我已发送／开始监听／确认收取”步骤。
