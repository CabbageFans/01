### 追加修复：全局审查逐目标送审快照

全局review没有单项inputFinal，旧判断不能证明某条问题针对当前正文。新增`reviewInputFinals`，从本次实际发送的actualCandidates逐项保存final，包括空串与动态尾帧；`petstoryReview.ts`供局部修订、当前错误标记、UI和导出共用。目标final在审查后已被重新生成、手改或采用新修订时，旧问题零新任务拒绝；无关目标改变、同文保存、仅增加未采用候选不误拒绝。

审查的格式repair只继承父快照，不能按修复时正文补造。旧单项只兼容其明确本目标inputFinal；缺快照的旧全局审查仅留历史。晚到问题只影响仍匹配送审原文的目标，原issues不删除。这些行为已覆盖真实保存／重开及合法性正反例。

### 追加修复：新会话探针超时

实机续跑遇到新会话准备探针超时。旧稳定检查依赖绘制帧，后台WebView的RAF暂停可能导致无法完成。现在在同次导航及原总截止时间内，取得两次一致的新文档／根路由／可用编辑器几何与空会话证据，不以RAF回调作为唯一继续条件。

只读probe超时或execution context短暂变化会清除旧稳定证据，再读完整事实；不再次loadURL、不注入正文、不点击发送。消息、草稿、生成中、旧文档、错误路由或无法聚焦仍拒绝，持续超时到原截止时间仍fail-closed。测试覆盖RAF不回调、短暂拒绝后的空态／草稿、持续超时及零输入事件。

### 追加修复：分析演员职责、动态配角与旧批次

新建真实分析暴露了内容错误：来源人类外观压过当前动物制作演员，短枝出现没有来源的交还。旧请求没有把制作演员资料作为独立职责完整传入。`productionCast`现在在有无旧plan时都独立发送：有当前profile使用当前配置；缺配置使用标明来源的旧plan角色；两者均无才用preset。有效确认身份和实际身份图片对相应角色优先；剧本确认不等于人物衣装确认，旧未确认设计不能覆盖当前制作配置。来源到演员的对应仍由豆包理解并撰写，程序不代写映射或修改已收到的故事／提示词。

现有配置UI可动态编辑必要配角，不只显示两位默认主演；每位已有演员可编辑来源称谓／别名标签及可清空的主角／配角职责。别名保留用户原值及顺序，不由程序猜测A／B／C映射；缺字段旧配置不自动补造对应。实际提供的别名／职责随请求绑定快照保存并核对，不能以旧人类稿或旧未确认设定反推。身份覆盖修复只保护仍有效的确认身份，旧未确认设计不能覆盖当前配置；没有用自然语言身份词频或正则替豆包判断创作内容。采用新方案后，旧批次若包含已删除目标，只在用户明确继续且原job归属／状态清楚时重新核对当前阶段缺失目标；旧请求、回复和失败仍保留，不能把删除目标算作完成或发送旧目标。

fresh-final已由正常原生创建入口从零开始，精确保存原故事与当前三角色资料／别名／主配角。唯一首次分析`e991`的真实新回复已在p7采用：动物身份、A／乐→噜噜、B→噜妹、C→小伙伴及主配角正确，动态4镜／7素材、三句原台词、持物与结局经独立内容审读通过；8项正式镜头正文仍为空，未伪赋专用来源。该实证只证明新建分析与空态承接通过，专用素材／镜头文字整链仍待完成，见第5节的不确定原任务记录。

## 2. 正常入口、模型／模式切换与恢复操作

1. 新项目正常保存故事，分析形成理解／资产／动态镜头方案，必要时采用并核对当前剧本与方案；使用“继续／补齐当前阶段提示词”顺序调用专用任务。旧项目使用同一入口，或画布／素材卡单项重新生成、批量生成及局部修订。无确认图时可以看明确文字计划，不能暗中提交媒体。
2. 在现有文字目标模型框选择创作目标；该设置不证明平台免费权益或原生槽位。generic／模式未定的有效专用计划可以完成文字阶段；真实模型／模式确定后通过Chat适配。改变用途、槽位或共同设计不能只改标签。显式generic覆盖旧媒体能力意图。
3. 单镜按首帧→必要时尾帧→视频推进，不强制每镜尾帧。后续读取当前已采用设计／边界。手改final保留，新结果单列候选；未采用时下游继续读旧采用版本，仍须通过当前资格检查。
4. 已提交未收取先选“只读重新收取”；歧义保留事实，不猜测采用。也可明确“放弃本次未收取候选／结束等待”，不删submittedAt、不改未发送、不表示平台取消／收取／采用、不释放真实租约；迟到回复不自动覆盖。
5. 处理窗口／登录／验证码／附件条件后，只有明确未发送且符合安全条件的原任务允许“处理阻断后继续原任务（未发送）”，沿原task经正式服务恢复。已提交不确定任务不显示重发入口。
6. 审查当前正文后选择实际目标及明确问题启动局部修订；审查后正文改变须先审查当前稿。review只返回问题，revise／repair完整正文仍由豆包产生。每原请求最多一次自动repair，新的明确操作保留新轮次和历史。
7. 用户正常确认当前故事与实际素材图片后，另行授权关键帧／视频节点或制作批次。单镜检查相关人物、道具、场景及父场景；整批检查依赖并集，实际guard同范围。连续媒体必须使用真实前镜视频／末帧，计划尾图不能替代。

同素材／同用途／同槽位仅换上传编号，或计划占位解析为同素材真实图，允许确定性引用映射；真实换图或职责改变交豆包修订。Chat看图附件表和目标媒体输入表独立。Seedance的@图片N及用途来自原回复；Seedream使用自身图片／编辑写法。正常导出逐项展示当前final、手改、新候选、引用与资格，不授权媒体。
