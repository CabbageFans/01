日期：2026-10-25（Asia/Shanghai）。基线 HEAD：`6ee0c42`。保留用户原有 `docs/UI_REFACTOR_TASK.md`；没有回退、提交、推送、Tag、发布或归档。独立 OpenSpec：`studio-ui-refresh`。

## 本轮结果

已在当前 Electron／React 工程实施六入口创作工作台，使用浅色中性外壳、白色面板和少量紫色强调。190px 导航可折叠，56px 上下文栏只放页面／Studio 项目、当前项目状态和浏览器入口。Mac 保留原生窗口控制，关闭、隐藏与 Dock 恢复策略不变；版本由原 `system.getVersion()` 读取。

创作工作台包含通用创作和萌宠短剧。通用四模式从弹窗移到主表单，提示词、图片／音频、独立执行账号、视频参数与批量模板集中呈现；创建仍只生成待执行任务。短剧分为故事输入、角色与分镜、制作准备、制作进度与素材，镜头改为有序列表＋选中详情，提示词采用“首帧／尾帧／视频 → 原始／优化／最终”两层切换。

Studio 项目与本地短剧明确分型。仅展示当前打开的本地项目；原 create/open 响应附带所选目录末级名称作为显示名，不写 `project.json`、不保存绝对路径、不建立全盘索引、不合并两种项目。切换 Studio 选择器不会重绑短剧，浏览账号也不会改变任务执行账号。

## 浏览器与状态边界

`App.tsx` 只有一个固定位置的 `BrowserPanel`，无动态 key。全宽、辅助、收起改变同一 wrapper 的布局；收起采用非零 960px 宽度、100% 高度的屏外平移，保持可合成树，不用 display:none 或 visibility:hidden 隐藏 guest。普通业务表单常驻，导航保留草稿、阶段和镜头选择。

配置／上传／提交阶段展开足够宽度的同一宿主；账号切换继续遵守原前台交互租约。短剧入口检查显示项目原账号，并在现有租约允许后等待布局再检查。全宽浏览器关闭时返回此前工作区，原会话／人工处理事件仍由原执行器完成。未重写执行器、调度内核、提交意图、单次发送或产物观察。

任务待授权、依赖阻断、原会话观察、生成、下载、文件校验与人工质量分别呈现。完成的短剧仅称“镜头素材已生成并完成下载校验”，没有整片合成完成状态。音乐、Dola、原生首帧／首尾帧保留未验收说明。
