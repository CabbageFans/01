## 1. 来源及使用边界

`女朋友在家vs女朋友在外 #水豚噜噜 #噜噜 #剪映 #情侣日常 #轻漫计划 [7681900323800079482](1).mp4`

本次读取媒体信息并按时间顺序抽查16个画面：0.2、1.8、3.4、5.6、7.7、9.2、10.8、12.8、14.4、16.0、18.0、20.0、22.0、24.0、26.5、28.9秒；另查看主要角色及双人场景的原分辨率画面。

原文件约30.1秒，1650×720、30fps，有音轨。它是横向参考片，不意味着现有产品应从9:16改成横屏。迁移造型、材质、表演和叙事方法，实际画幅仍按本项目已批准配置。

本文件区分：**样片可见事实**、**建议的产品规则**、**人为编写的示例提示词**。没有读取用户当前源码或实际生产提示词，没有进行豆包新旧生成对照，不得将下面示例称为已生成或已验证质量提升。

`frames/`中的图是抽出的原样片画面，含原字幕/标题，仅供这次开发分析。它们不是自动批准的生产角色参考图，也不要随产品默认打包为商业角色素材。实际生成继续使用用户项目已经选择的参考图。

### 可见的共同美术特征

- 拟人化圆润3D角色，不是野生水豚纪录片风。
- 主体浅黄／金黄，吻部更深更橙；小圆耳、大头、短肢。
- 细腻、较光滑柔和的角色表面；高光眼睛；布料有褶皱和花纹。
- 客厅和面馆都有具体材质和生活用品，背景适当虚化。
- 主要靠清楚的角色关系、反应与表演推进，不依赖持续旋转炫技镜头。

### 本样片的叙事，不是所有剧本的固定模板

家中“谁是大王”的得意姿态，与面馆“不敢自己沟通”的怯场形成反差。噜噜在两个环境中配合/关注噜妹。可借鉴“表情反应讲故事”，但不能将未来所有故事改成同一套面馆、香菜和称王情节。

## 3. 优化器应采用的分层

`项目身份参考 → 当前造型 → 镜头开始/结束状态 → 参考图用途与真实顺序 → 图像/视频模式 → 最终文本`

同一角色的完整说明可以存进配置及Chat优化上下文，但不等于每条视频提示词都重复完整外观段落。已经由首帧定义的内容，用简短保持项承接；把文本预算留给动作、表情、视线和结束状态。

下列示例全部是**基于本样片整理的人工示例**，不是工具现有生产提示词，也不是豆包实际输出。请求时长、画幅、素材数量均以当前真实免费入口和项目方案为准。

## 4. 四组提示词示例

### 示例一：噜妹在家得意——Seedream首帧

**前提：** 图1是用户已选择的噜妹角色参考，包含本场粉色衣装和头饰；剧情确认本场披黄色柑橘斗篷。不提供不存在的参考图序号。

**不足示例（为说明问题而拟写）：**

> 噜妹在客厅很得意，3D可爱风，高清。

**优化示例：**

> 以图1中的噜妹为角色参考，保留浅黄色圆胖身形、宽橙色吻部、粉色荷叶边软帽与衣装、帽顶浅橙盘状装饰和双叶嫩芽。本场披浅黄色柑橘图案斗篷，在米色沙发前站立，身体微侧向画外的噜噜，下巴略抬，双眼半眯，嘴角得意上扬，短臂自然靠近腰侧。单张中近景，角色眼睛高度的平视机位，头饰完整入画；温暖侧光，布料褶皱清楚，生活化背景轻度虚化。保持参考中的圆润3D材质，不照搬参考图上的字幕或标题。

**补足：** 角色身份、服装归属、单一时刻的姿势、视线对象、构图；不是加一串画质形容词。新项目已有别的服装时不用这个斗篷示例。

### 示例二：面馆双人——Seedream首帧

**前提：** 图1是噜噜身份参考，图2是噜妹身份参考。若图2带家中斗篷，本次已确认的编辑要求是不沿用斗篷；衣装与头饰其余部分保留。

**不足示例（拟写）：**

> 噜噜和噜妹在面馆吃面，噜妹委屈，可爱3D。

**优化示例：**

> 图1提供噜噜形象：完整小橘子头饰、白底草莓短裤；图2提供噜妹形象：粉色荷叶帽及衣装、浅橙盘状头饰与双叶嫩芽，本场不沿用斗篷。保留两者浅黄圆胖身体、宽橙吻部和眼睛特征。在木质面馆同桌而坐，噜妹在画面左侧，噜噜在右侧；面前各一碗面，噜妹那碗表面有清楚可见的香菜。噜妹握筷停在碗边、低眼看香菜，嘴角微垂；噜噜侧头看她，保持关注。双人中近景，面碗与双爪可见，暖光、圆润3D材质、背景轻虚化，两人头饰与衣服不互换，不复刻参考的文字覆盖。

**补足：** 谁对应哪张参考、两人相对位置、可见道具、起始表情和真实互动关系。左右只对这个镜头有效。

### 示例三：面馆委屈转向求助——Seedance首帧视频

**前提：** 实际上传的是已经选择的面馆首帧，不再使用“图1噜噜肖像、图2噜妹肖像”这组图片含义。采用当前片段允许的时长，示例用顺序节拍，不要求模型精确到帧。

**不足示例（拟写）：**

> 噜妹看向噜噜，委屈，动作自然，保持一致。

**优化示例：**

> 从上传的面馆首帧接着表演，保持画面左侧噜妹、右侧噜噜的形象、服装、头饰、桌面和两碗面。噜妹先看着自己碗上的香菜，握筷的动作停住，眼睑稍低、嘴角下压；短暂停顿后缓慢抬眼看向噜噜，头部微偏向他，肩膀稍内收，表情由不满转成犹豫求助。噜噜注意到她的目光，轻轻侧头回应，保持注视，不抢做另一组动作。筷子始终由噜妹握持，两碗面留在原位置。固定双人中近景，连续完成这次反应，不额外切镜；结尾停留在噜妹向噜噜求助、噜噜关注她的状态。

**补足：** 触发原因、主动作、反应节拍、道具保持和终态。未给台词时不自动添加对白；有确认过的台词，则按真实支持的能力补说话人和原文，不编配音系统。

### 示例四：同一动作的尾帧编辑＋Seedance首尾帧

**A. 尾帧编辑前提：** 上传并编辑上例实际首帧。

> 以这张面馆首帧为底图，只将画面左侧噜妹的表情和头部姿态调整到求助终态：目光转向右侧噜噜，头部略偏向他，肩膀微收，嘴角轻压，筷子仍握在原来那只前爪并停在面碗上方；噜噜轻微侧头看向她。保持两位角色的脸型、颜色、当前衣装、头饰，保留两碗面和香菜的位置、桌椅布局、机位、画幅与光线；允许随姿态合理改变局部衣褶和遮挡，不额外增加人物或动作阶段。

**B. 首尾帧视频前提：** 首帧和上一步选中尾帧实际绑定在当前入口的两个专用槽位。

> 以首帧作为开头、尾帧作为目标结尾，连续表现噜妹从低头看香菜转向噜噜求助。先延续首帧中噜妹看碗的姿态，让握筷动作轻轻停顿，眼睑和嘴角显出委屈；随后缓慢转动头部和目光朝向噜噜，肩膀微收。噜噜感受到她的目光后小幅侧头，视线落在她脸上。最后自然收敛到尾帧的头部方向、视线、持筷位置和双方姿态，稍作停留。全过程保持身份、衣装、头饰、面碗和桌椅一致，固定双人中近景，不切镜、不让筷子换手或面碗移动。动作连接两个端点，而不是只把两张画面做变形过渡。

**补足：** 起点、终点和中间动作各自明确。专用槽位不存在时不能沿用“已绑定首尾帧”的说法，需改为现有参考生成分支的措辞与界面状态。

## 5. 三个不该采用的“优化”

1. 给所有镜头无条件添加同一大段两主角外观和斗篷描述：会污染单人镜头与场景换装。
2. 生视频完整重述首帧并增加与图不符的站位、背景、机位：容易让模型同时面对两套相互冲突的起点。
3. 以字数增长、关键词数量或一个假“质量分”宣布改善：必须检查信息是否正确、实际绑定是否匹配、最终发送是否完整；真实生成效果仍由用户看结果。
