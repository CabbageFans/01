## 五个必要表面

- **字体与排版**：系统中文字体；正文 14 px、一般 UI 13 px、辅助 12 px，11 px 仅元数据。画布缩放使用内在字号，完整正文在独立可滚动编辑器查看。标题、按钮、表格和标签在各页面层级一致。
- **间距与布局**：192 / 180 px 导航，60 px 上下文栏；同一行按钮同高；画布保留左故事／素材与右四列镜头行。所有主要页面没有整页横向溢出；长素材、分镜、任务、成果可以纵向滚动。
- **颜色与 token**：`#F4F6F8` 背景、白内容、`#087F72` 主操作；提醒与失败只用小面积语义色。无大面积紫色、渐变面板或新增装饰性统计。
- **图片质量与资产**：使用真实历史抽帧及其正常 contain 预览；不以 CSS / SVG 绘图替代媒体，不以静帧冒充可播放视频。原始画面内字幕属于样例资产，并非新 UI 文案；不把这些历史帧认作本故事新生成或已验收素材。
- **文案与内容**：六阶段、目标对象和下一步清楚；通用创作无可见入口；内部 ID / JSON / 规则正文不进入主流程。人工发送仅在独立评审入口注明的未来分支；默认页面与源码事实保持工具自动发送。
