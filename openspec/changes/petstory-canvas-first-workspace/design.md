# Design

## Context

动机见 proposal。已有 Panel 渲染推荐和任务区，Canvas 叠加工具栏、状态栏，CSS 固定视口高度；批次持久化和候选采用已经存在。App 保持唯一 BrowserPanel，通过图片操作台账维持非零尺寸后台宿主。

## Goals / Non-Goals

**Goals:** 复用现有项目与任务边界，将正常交互收敛到画布；生成完成与正式采用分离，失败有直接恢复入口。

**Non-Goals:** 不重新设计节点列、不新增工作流引擎或浏览器、不改变素材页图片反馈、不生成新媒体、不改写用户故事。

## Decisions

- 画布阶段向 App 声明模式，workspace-content、page-fill、Panel、stage-content、workspace 和 viewport 全链 flex/min-height:0；其他阶段仍滚动。指定多余区块按条件不渲染，不用折叠隐藏。
- 视角从真实节点 offset 边界求解当前行和视口中心。首次或适应采用可读缩放下限，长项目沿纵向平移；ResizeObserver 保持原中心。revision/普通进度更新不重置用户视角。
- 继续使用原 promptBatch、jobs、parsedResult、adoptPromptCandidate。候选成功保存就推进该目标，不依赖采用；同批引用快照明确标明仅文字设计，不进入正式 final/媒体附件。
- 资格查询返回较新项目时同步原Store及批次计数；同版本结果不反复替换plan引用。创作hash跟随真实前镜边界选择，避免尾帧已选时因未选视频的后续确认而假过期；保留真实事实变更的拒绝和原合同。
- 用户修改绑定节点及具体候选，携带意见与当前事实进入已有 runtime Chat 完整正文合同；主动多轮与一次自动结构修订分开。旧正文和媒体直到明确采用前保持。
- 按2026-10-31用户增量增加手动修改弹窗，与自然语言修改并存；复用saveShotPrompt与项目串行写入，传打开时expectedFinal和可选baseJobId，拒绝同项并发覆盖。可用候选直接手改时保留正确来源及合同，确定保存后展示final，旧候选保留历史但不再遮挡；未保存草稿登记到原导航保护，保存不启动媒体。
- 文字任务带画布后台关联，自动修订继承；旧批次只通过精确 job 关联识别。自由聊天不归为后台。沿原可合成 Webview 输入/回读，用户主动会话入口与执行自动事件分离。
- 首尾帧图片按钮经现有ImageOperationService登记精确shot/kind，原generateShotMedia只增加内部operation关联并沿用编译／采用正文，不产生新文字请求；共用图片进度、恢复与候选预览，不按所有image或production任务扩大后台权限。
- 未发送原任务复用原身份重试，收到未保存回复补收取；受理不明先观察并显示查看入口。修订失败不清空已经保存的其他候选。

## Risks / Trade-offs

- [窗口窄于全部横向节点] → 保持可读比例和空白平移，不无限缩小。
- [平台验证码/不明提交] → 保留原运行事实，显示真实状态；不自动重发、不绕验证。
- [候选与手改冲突] → 保留旧版本，明确提醒替换对象，采用只影响选定项。
- [原生后台输入依赖真实视口] → 维持现有宿主几何及合成，用真实 UI 检查进度与展开事件。

## Migration Plan

仅新增可选关联元数据，旧项目正常读取；不迁移或直接编辑用户 JSON。完成工程与真实 UI 验证，报告区分离线、真实平台及阻断；结束短时诊断实例并普通启动。
