# Proposal

## Why

关键帧、镜头视频和全景页被重复说明与待处理面板占据，画布固定高度和偏移使内容难以操作；文字候选逐项暂停且自动展开豆包，打断完整创作流程。

## What Changes

- 删除本页阶段推荐、待处理事项、重复标题及技术状态，只保留紧凑导航和画布工具栏。
- 贯通剩余空间布局，按真实节点边界居中、适应与定位，保持既有网格及横向列关系。
- 一个入口连续生成本批候选；结果逐项或本批确认，自然语言修改取得完整新候选，保护已采用正文和媒体。
- 复用常驻 Webview 图片后台执行机制，明确关联画布文字及修订，仅主动入口展开对话。
- 将恢复放到相关节点，保留原任务与受理不明保护；真实 UI 验证并如实报告阻断。

## Capabilities

### New Capabilities

- `petstory-canvas-first-workspace`: 以画布为主的文字生成、确认、意见修改和后台恢复。

### Modified Capabilities

无已归档主规格。本增量覆盖在途旧画布、journey 和 prompt-pipeline 中冲突的顶部大区块及逐条暂停要求；其余业务和第三阶段图片反馈保持。

## Impact

修改现有 App、Panel、Canvas、视口与样式、项目文字批次、请求及修订服务、后台识别和 BrowserPanel 接线。复用单一项目、TaskService、候选、采用、恢复与下载，不增加执行器、模型或 P5，不自动生成媒体、不提交推送发布。
