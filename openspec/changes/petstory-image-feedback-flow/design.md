## Context

素材卡目前显式运行 materialPrompt 并让用户采用，局部编辑只生成文字计划。既有 Chat 的校验／有限自动修订、Production 的任务绑定／参数回读／文件上传／下载和 ImageReview 的候选采用已存在。应用壳会在 injecting/submitting 自动展开浏览器，现有屏外 Webview 宿主本身可保活。

## Goals / Non-Goals

**Goals:** 在同一 project.json 追加少量图片操作关联，使单次意图可恢复、可去重，并由实际任务推进；图片确认保持唯一正式引用入口。

**Non-Goals:** 不建第二调度器、素材库或浏览器；不修改故事确认、自由 Chat 回复采用、视频工作流和画布布局。不恢复免费、人工入口检查或免责声明。

## Decisions

- 用 project.imageOperations 关联 requestId、target、basisHash、明确 baseAssetId/baseSha256、feedback、chatJobId、taskId、outputAssetId 和阶段。操作入口经过版本检查与项目串行事务，轮询推进同一记录；不以组件本地布尔值推定成功。
- 首次生成先核对适用 final；必要时调用现有 Chat 请求与自动修订链，只自动采用本操作新建且仍匹配当前事实的回复，再启动既有单项素材 Production。手改优先，历史候选不任意自动采用。
- 修改采用新会话上传具体基图的路径，复用已有 Production 图像附件及执行 guard；用户原话和当前素材事实组成有来源的编辑请求，不伪造豆包文字，也不覆盖原 final。选择该路径以覆盖上传图、旧候选及无原会话场景。
- Store 推进只负责调度既有任务，UI 从操作与台账派生准备／生成／保存／待确认。主动查看按实际 taskId 与图片来源定位；自动流程不调用 revealBrowser。
- 素材卡及共享预览只呈现图片决策；选定 ID 传递到反馈弹窗再到正式服务。自动预览限定本页本素材主动操作，其他页面不弹窗。正式采用服务和下游复核不改。
- 仅新图片操作不触发应用壳展开；执行至候选保存期间保留同一宿主的视口交集、正常合成及显式输入命中，由不透明工作区覆盖浏览器并接收用户点击，不 display:none、不卸载、不改 partition。现场平台会在屏外只保留隐藏编辑器，故不能用屏外位置证明执行控件可用。导航前沿现有草稿探针回读，用户输入／生成中则暂停。

## Risks / Trade-offs

- [平台实际入口或登录不可用] → 就地显示真实原因，保留基图／反馈／任务，不补造产物。
- [发送受理不明或下载失败] → 保留原任务并只读收取／只补下载，不新增发送。
- [用户改方案或切换项目] → 当前事实摘要和目标核对失败后保留旧操作，不覆盖新项目。
- [真实原五镜头文件本机缺失] → 明确记录；原故事只读夹具做离线回归，真实验证仅使用实际可得项目隔离副本，不声称不存在的通过。

## Migration Plan

旧项目无 imageOperations 时行为兼容，不删除历史提示词或资产。有效需求在顶部注明本次覆盖条款，在途旧规范添加指向本变更的优先说明；不归档历史变更。代码、测试、报告和截图留本地，最终普通启动应用。
