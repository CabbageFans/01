## Why

基础素材页仍要求用户准备、审阅和采用提示词，图片反馈只生成文字计划，打断创作者的选图过程。本轮将已确认的“生成图片 → 查看结果 → 提出修改意见 → 确认采用”接入既有任务与候选服务。

## What Changes

- 人物、道具、场景一次生成操作自动衔接必要 Chat、有限自动修订、正式正文保存、图片任务和候选下载。
- 反馈绑定预览中选定的具体图片及用户原话，上传该文件并生成新候选，支持未采用图、上传图、旧候选及连续修改。
- 素材页删除提示词生产入口、生成记录／诊断、更多菜单和局部编辑计划；保留图片确认、上传与真实会话入口。
- 图片流程默认后台执行；显示真实任务阶段，下载完成后才呈现可预览结果；恢复不重复发送。
- 本次授权仅覆盖所选图片目标，采用仍独立进行；保留画布、正式素材与历史，不启动视频。

## Capabilities

### New Capabilities

- `petstory-image-feedback`: 素材一键生图、选定基图自然语言修改、候选采用及后台恢复。

### Modified Capabilities

无已归档主规范。本增量覆盖在途 user-journey / asset-first 中冲突的手动提示词、更多菜单和强制原会话要求，其余范围不变。

## Impact

复用 PetStory Chat / Production / ImageReview、TaskService、账号 Webview、IPC、contracts、Zustand 与 project.json。修改素材卡、共享图片预览、后台可见性与相关测试。没有新执行系统、数据库、图片库或模型 API；不改视频流程、不重做画布、不发布、不进入 P5。
