# Proposal

## Why

首次分析仍直接采用综合媒体正文，缺少专用合同的旧稿与通用稿可能进入已知模型，长请求显示差异又使已有回复无法收取并阻断项目。需要让正常首次、单项、批量与修订使用同一专用 Chat 与采用链，恢复真实回复而不重发。

## What Changes

- 分析仅设计故事、动态资产、空间与镜头；兼容带回正文只作草稿，增加阶段提示词补齐及持久化批次。
- 文字目标模型独立于网页能力；共享来源、方言、模式、事实和引用资格检查覆盖媒体入口与导出。
- 已发送普通 Chat 按原账号会话、运行、唯一轮次及目标关联只读恢复；可明确结束等待，保留历史与迟到候选，按实际依赖阻断。
- 自然语言字幕约束有限等价识别，保留引用、逐字台词、次数及声音格式的严格检查；每请求最多一次自动修订。
- 使用原故事新建隔离方案及原五镜头5+3+5专用任务实测，保留原回复与手改，正常导出、重开并启动应用。

## Capabilities

### New Capabilities

- `petstory-prompt-pipeline`: 专用文字生产、提交资格、原回复恢复及阶段推进闭环。

### Modified Capabilities

无已归档主规范；保留此前变更。

## Impact

复用 PetStory project.json、TaskService、账号隔离、Chat执行器、画布、引用编译与P4下载恢复。增量修改contracts、请求／收取／采用服务、素材／生产／导出校验、store、IPC和对应UI及测试；不新增依赖或模型API，不开发P5，不自动提交／推送／发布／归档。
