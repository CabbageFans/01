# Design

## Context

动机与范围见 proposal；本轮任务书和用户最新指令优先于历史提示词专项及无真实请求约束。已有 `PetStoryPanel`、`PetStoryMaterials` 与 `PetStoryPlanAssets` 使用同一 `usePetStoryStore`；普通 Chat 已经由 `prepareChat → TaskService → bindRun → collectChat` 保存原回复与候选，P4 已有顺序制作、原任务观察、下载和本地资产协议。旧 final 与 optimized 分开，手改和上下文变化不自动采用。`App` 已固定挂载唯一 `BrowserPanel`。

## Goals / Non-Goals

**Goals:** 用节点重组既有业务入口，以当前项目动态数组构成一份可编辑生产视图；任何生成动作仍走原服务，保存、来源、候选及任务输入可核对。

**Non-Goals:** 不增加画布业务副本、自由 DAG、生成执行器或新运行时；不复制参考仓库源码、后台、API、品牌和示例媒体；不修改规则质量、语义编译标准或开发 P5。

## Decisions

- 按目标截图组织固定列网格，左侧故事节点、右侧动态镜头行，素材区在同页可展开。图片和视频列独立，首尾图分别显示，长文本使用可滚动全文及就地放大编辑。相较自由节点编辑器，固定列能持续保持镜头、引用和产物的对应关系，无需引入依赖。
- 画布只保存 translate/scale 视角；空白拖动与交互控件隔离，缩放锚点与聚焦使用真实节点边界。行高容纳长文本与竖图，适应画布不能成为默认不可读字号。普通状态回填不重置视角或当前编辑草稿。
- 继续使用原 project/plan/prompts/assets/jobs/production 数据；节点编辑经现有保存入口完成，不另存 canvas final。故事保留原用户输入与当前故事；提示词显示 final 全文和真实来源，候选、当前采用、原任务与时间分别呈现。保存时仍执行 revision 与制作锁边界。
- 新文字调用复用既有普通 Chat 请求与回读；“生成全部提示词”遍历当前镜头实际需要的 firstFrame、endFrame、video，并串行等待原 job 保存和收取，遵守当前单个待收取任务约束。打开页面、展示素材、缩放与聚焦不调用该动作。失败或受理不明停止相关队列并保留原任务，不重发。
- 保留现有输入模板和编译器；仅在 Chat 回填、来源显示、候选可见、项目绑定等阻断本页使用时补最小接线。生成请求前保存草稿或阻止脏文本发送，任务始终读取用户看见的已保存 final；已有 compiled snapshot 单独展示真实用途映射。
- 基础素材仍由用户确认具体图片后进入关键帧；图片、视频按钮各自复用当前 P4 流程，下载按钮只下载。原生产流程及安全门禁不因节点存在而隐含批准。历史媒体仅通过已有 asset/task 标识关联，不按文件名臆测归属；没有产物时明确未生成。
- 实测只使用 `FIVE_SHOTS_REVIEW.md` 对应原项目，确认当前保存镜头后按其当前模式取得至少 5 首帧、3 尾帧、5 视频文字结果。若当前项目已有用户后续修改，保留它；新候选原样可见，手改 final 不覆盖。通过正常业务链记录 taskId/runId/时间与原回复，不手改项目 JSON 注入结果。
- 现有 App/BrowserPanel 宿主与账号 partition 结构保持，画布导航只改变普通工作区。实际 Electron 验证切页、展开与缩放不会新增任务或重建 guest；真实生成与离线测试证据分别记录。

## Risks / Trade-offs

- [单项 Chat 较慢或平台回读失败] → 串行绑定与自动收取，保留已完成部分和原任务，只读恢复；如实报告实际成功数，不编造候选。
- [手改与异步回填冲突] → 本地编辑草稿保留，按字段显式采用候选，保存使用当前 revision；刷新只更新未编辑字段。
- [历史项目缺少新基础清单或旧引用无对应图] → 保留原数据和诊断，展示已有媒体但不批准新提交，不为填满画布伪造图片或引用。
- [过宽画布与长文阅读] → 清晰固定列、平移和聚焦，完整文本弹层；不通过极小缩放冒充可读总览。
- [媒体生成未实测] → 仅映射已有真实豆包结果并核对空状态；用户未点击不主动批量生成，报告入口接线与实际运行分别记录。

## Migration Plan

不迁移、不重写既有用户项目；只扩展必要可选元数据并保持旧文件可打开。保留当前未提交修改及旧 change。完成必要类型、构建与相关测试和严格 OpenSpec 校验后，保存实际界面截图，交付 `docs/STORYBOARD_CANVAS_REPORT.md` 并以准确命令启动当前应用；不提交、推送或归档。
