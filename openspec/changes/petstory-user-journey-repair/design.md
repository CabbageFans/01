# Design

## Context

动机见 proposal。当前 PetStoryPanel 同时展示画布与旧四阶段，实际服务已具备原子保存、普通 Chat 专用创作、候选采用、剧本与图片确认、单节点制作及原任务恢复。主进程现有资格、素材与模式校验是最终权威；源任务和项目的未决状态不得由 UI 修正为成功。

## Goals / Non-Goals

**Goals:** 以同一 project 状态派生六阶段和推荐下一步；主操作与恢复处理置于画布缩放之外，复用既有组件和服务，准确保留人工确认、手改和实际发送事实。

**Non-Goals:** 不新增持久化阶段状态、通用 DAG、第二调度器、模型 API、提示词框架或 P5；不通过自动批准图片、改写项目或测试后门完成验收。

## Decisions

- 用轻量只读 UI 投影计算阶段与实际目标计数，避免新增可与项目事实漂移的阶段持久字段；允许查看任意阶段，推荐首个可处理缺项。
- 新建弹框明确账号和关联 Studio 项目；直接输入为默认模式。保存和分析按已有单对象接口顺序执行，保存失败终止；异步结果以可见成功交接进入采用、确认方案。
- 高级编辑保留原数据源，草稿对象及保存／定位／放弃可见。异步回复不覆盖正在编辑的草稿，保存继续使用 revision 校验，避免过期整项目写入。
- 当前页素材和节点使用只读生成资格 IPC，主进程复用原有确认、正文、引用、文件与模式检查并返回结构化对象定位；实际提交仍重复执行正式门禁。选择前端重写校验会造成漂移，因此不采用。
- 保留当前真实自动 Chat 发送链，等待／未发送／已发送／受理不明与需要采用分开显示；原任务恢复、只读收取和结束等待进入固定处理区，ID 与原 JSON 进入诊断详情。
- 成果仅按当前方案目标与实际登记产物计数，不采用最后 production 批次的 complete 推定全项目；安全定位只接受已打开项目和资产 ID，不接受任意文件路径。
- 真实验收只操作用户可见控件，读数据仅核对。使用同一用户故事的新建隔离项目及原五镜头；文字、图片美术接受和媒体授权分开记录，平台阻断不伪造通过。

## Risks / Trade-offs

- [平台响应或原任务受理不明] → 保留原状态，当前页面解释并提供只读恢复，绝不自动重发。
- [历史方案缺基础清单或资格过期] → 保留成果，显示具体缺项和真实补齐入口，不放宽门禁。
- [长画布和窄窗口遮挡动作] → 六阶段与处理区保持在缩放外，在 1440×900 和 1280×800 实际窗口核对。
- [只读查询与异步回复竞态] → 以项目 revision 和当前能力为请求边界，过期结果丢弃，不改变项目数据。

## 指定视口验收补充（2026-10-29）

- 通过仅未打包、显式 `--dev-viewport-size=宽x高` 的启动参数设置内容区尺寸，默认窗口仍为原1400×900外框；不新增IPC或业务状态写入口。记录实际外框与内容区，并以真实页面点击和截图验收，拒绝非法／重复／越界参数。
- 全文编辑弹窗正文限制高度并内部滚动，textarea随视口限制高度；返回与保存保留在独立页脚，避免长候选将关键操作推到窗口外。

## Migration Plan

不迁移用户 JSON、账号 partition 或任务；增量扩展只读契约。保留旧在途变更及未提交文档，完成相关交互测试、工程检查与构建后保存本地 ignored 截图证据，报告当前真实覆盖并普通启动应用；不提交、推送、发布或归档。

## 2026-10-29 获批设计实施约束

批准事实见 `docs/ui-design-review/2026-10-29/full-product-design/APPROVAL.md`，视觉摘要见同目录 approved-design.json。颜色／布局／字体／控件／交互不再自行改版。

- 使用现有 Ant Design、Zustand、IPC、TaskService、账号池和 project.json；新增可选采用／调整元数据，不新建执行器或数据库。
- 图片候选保存与正式采用是两个事务。正式采用按项目 revision、对象用途、当前创作依据、实际文件及确认事实核对；新候选不提前改变旧正式指针，替换后旧图和成果保留，相关内容待复核。
- 旧材料的有效 approved 兼容；没有确认事实的历史关键帧不推断为用户已批准。预览仍可读旧图，媒体引用拒绝未采用图。
- 自由 Chat 绑定单一目标、基线版本和关联会话。进入前等待或阻断活跃写入，不抢草稿。会话中的完整可辨认助手回复经稳定读取后供用户单选，确认前再次比对目标和原回复；解释／反问不能被程序改写成正文。
- 对结构不完整的选定回复，可让豆包依据当前规则整理；保留原回复和候选，最终正文仍来自真实模型返回。
- UI 阶段仅导航／定位，不持久化虚假的完成状态。阶段 4／5 不裁列、不销毁编辑器，原视角与浏览器宿主保持。
- 能力门禁、结果不确定不重发、前台租约、免费权益未知停止等已有约束继续有效。没有真实平台证据的部分不得勾选实机完成。
