# Proposal

## Why

当前内置主演、特定美术及旧人物描述仍可能进入分析、关键帧和视频请求。采用上传图后，图片就绪又依赖旧基础提示词和身份文字，导致新图不能真正决定形象。

## What Changes

- 新项目角色和风格由剧本及用户输入决定，保留历史角色 ID 和真实内容。
- 明确采用人物图后以图片作为视觉依据，旧基础提示词保留历史但退出活跃使用；上传不要求文字任务。
- 按阶段组织当前事实，关键帧安排画面、视频安排表演，准确绑定图片、制作标签和原台词说话者。
- 换图仅影响使用该角色及真实连续依赖的镜头，旧媒体保留，正常操作时处理所需目标。
- 保持现有画布、图片反馈、候选采用和普通 Chat 执行链。

## Capabilities

### New Capabilities

- `script-driven-cast-reference-first`: 剧本驱动角色、采用图决定形象、分阶段有效写作事实与局部版本处理。

### Modified Capabilities

无已归档主规范；本变更覆盖旧在途变更中的冲突默认要求，不改变其历史验收事实。

## Impact

PetStory 项目、素材及图片采用服务、contracts、Chat 请求与修订、生产编译和资格检查、最小前端接线、drama 适配规则与行为测试。无新框架、付费模型、迁移向导或自动媒体批次。
