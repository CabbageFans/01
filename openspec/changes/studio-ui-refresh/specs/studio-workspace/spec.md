# Studio Workspace

## Purpose

将现有 Studio 与 P4 短剧功能组织为清爽的创作工作台，使用户能通过清晰页面完成创作、查看任务和素材、处理账号与维护，并在导航过程中保留真实会话、表单、执行状态和既有安全约束。

## ADDED Requirements

### Requirement: 六个真实页面与入口完整

系统 SHALL 提供项目总览、创作工作台、任务中心、素材与下载、账号与浏览器、设置与诊断六个入口。已有操作 MUST 连接原服务，空状态及数据范围准确，版本来自实际构建，Mac 只显示一套窗口控制。

#### Scenario: 继续工作
- **WHEN** 用户切换页面再返回创作
- **THEN** 未保存表单和选中镜头保留，Studio 项目与短剧绑定保持独立，执行账号不因浏览选择变化

### Requirement: 浏览器常驻

系统 MUST 保持每个已挂载账号浏览器实例与隔离会话稳定；导航、开合与全宽切换不得创建第二实例、重置会话或提交任务。需要交互时 SHALL 显示同一受租约保护的宿主。

#### Scenario: 多次导航与展开
- **WHEN** 用户依次访问所有页面、展开收起辅助浏览器并进入全宽账号页
- **THEN** 浏览器实例身份与 partition 不变，任务数和提交次数不变，执行及观察监听仍存在

### Requirement: 创作与短剧阶段

系统 SHALL 提供通用四种模式的真实创建表单与批量工具，以及短剧的故事输入、角色与分镜、制作准备、制作进度与素材四阶段。动态镜头、角色、final、备选和编辑锁 MUST 保留；制作结束 SHALL 仅表示镜头素材，不表示成片。

#### Scenario: 制作锁定
- **WHEN** 已有 production 的项目被打开
- **THEN** 方案可查看但不能编辑、再优化或重做；素材及原任务观察可用，打开不授权制作

### Requirement: 状态与范围准确

系统 MUST 区分待授权、依赖阻断、已受理观察、提交不明、生成、下载、校验与人工质量。下载重试 SHALL 仅下载，质量拒收 SHALL 不自动重跑。账号额度 SHALL 注明来源，未验收能力不得显示为生产可用。

#### Scenario: 素材与人工处理
- **WHEN** 已生成产物下载失败或提交不明
- **THEN** 分别提供重新下载或核对原会话，不能用普通重试产生重复生成；批量下载保持项目、批次和明确非空选择

### Requirement: 可读与可访问布局

系统 SHALL 在 1440×900、1280×800 和现有最小窗口提供可滚动内容、可达主要操作及清晰焦点。辅助浏览器空间不足 SHALL 覆盖显示，不挤压表单；图标操作具备名称。

#### Scenario: 窄窗口
- **WHEN** 用户缩小窗口并打开浏览器或详情
- **THEN** 主要按钮可达，文字不竖排，表格横向滚动局限在表格容器，Esc 可关闭普通辅助区
