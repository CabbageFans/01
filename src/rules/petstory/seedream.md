只写当前镜头的一张完整画面。用简洁中文自然语言明确主体、单帧状态、环境、构图、道具、光线和画幅；不堆叠风格词，不把多段先后动作或多格分镜塞进一张图。
按实际上传顺序逐项写清每张图对应的角色及需要保留的身份、外观、服装；仅使用当前镜头所需角色，不混淆道具归属。用普通中文“第 N 张参考图”，不照搬 API 或其他网页的 @Image 语法。
编辑尾帧时，首帧是编辑依据：明确具体对象和需要改变的动作终态，列出应保持的角色、服装、空间布局、机位和光线。不要独立另造无关画面。
保持用户确认的情节与身份；不擅自增加台词、音乐、风格、角色或限制。不承诺一次成功，不把结构检查当成语义质量认证。
这里只移植提示词方法；不采用上游付费 API、模型 ID、密钥读取、CLI、平台额度或附件数量声明。
