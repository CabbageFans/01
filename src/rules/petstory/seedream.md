# Seedream · petstory-asset-first-v3

规则方法来源：a86582751/doubao-seedream-image-skill，commit 0f700d9d5c32ad57f91a9575cec1f62abcbd56e2；SKILL.md Prompt Optimization Rules、references/prompt-guide.md。MIT，完整许可保留于本目录。复用已核查方法，不采用上游付费 API、密钥、脚本、模型和额度声明。

人物基础图：单幅可复用身份参考，说明剧情身份、体态面部、服装饰物、稳定特征和统一风格。用户参考与明确设定优先，未知设计可给出明确候选，待确认状态只放元数据；不固定当前镜头动作或姿势，不增其他人物。
道具基础图：突出形状、颜色、材质、比例和辨识细节，明确关键状态；比例需要依据，未要求时不加入持有者，不把普通背景细节全建资产。
场景基础图：地点、时间光线、布局、地标和空间关系；默认无人物。同地其他视角以已确认主图为编辑参考，保持环境，不独立随机造景。
首帧组合：只用本镜已确认的人物、关键道具、场景及需要的连续状态，逐项明确每图提供什么。围绕开始状态写一个明确静态时刻，说明构图、景别机位、相对位置、姿态、表情、视线、道具归属及空间关系。身份不等于永远同姿势；外观标准和本镜状态分层。不要提前画出后续已完成终态，不拼贴多个时间阶段。
尾帧编辑：只以实际选定首帧编辑到结束状态；列明对象与必要改变，以及保留的身份、服装、道具外形、环境、光线和画幅，允许动作产生合理衣褶与遮挡。不要独立创造另一图；端点不可达时提示调整分镜。
正文按本次目标素材标签表写明“第N张参考图”及其用途，不能沿用Chat看图序号；计划图可以写明确标签，计划和未绑定状态放元数据。程序仅对正文既有引用进行确定性编号映射，不追加引用、编辑对象或保持项替模型补写正文。入口支持 @ 引用时必须选实际菜单节点；不支持时仅用已有且实际可执行的普通中文用途映射适配，不要求用户另行勾选。不能用裸 @ 文本冒充节点，不能把图片编号固定成某人物。
完整明确且无冲突优先，无字数、关键词数量门槛；不堆风格词，不编新台词、关系、剧情、旁白或字幕，不改变平台生成标识。生成成功不代表用户已经接受图片。
